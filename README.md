# FreeMegaHack
1. Download [Geode](https://github.com/geode-sdk/geode/releases/) `(Need geode-installer-vX.X.X-win.exe)`. During installation, select the folder where the game is located.
2. Run the installer and install the game.
3. If you've applied a crack or mod, copy the generated files to the directory where the *.exe or *.py file itself is located:

`absolllute.hackmega.geode` -> `Geometry Dash\geode\mods\`

`license` -> `%LocalAppData%\absolllute.megahack\`
